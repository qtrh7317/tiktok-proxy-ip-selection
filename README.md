## 机房 IP 和住宅 IP，差距落在哪里

TikTok 判断你是什么用户，看的是 IP 的 ASN 归属，也就是这段地址是分给家庭宽带运营商，还是分给机房。

这个判断影响三件事。注册环节，ISP 网络配安卓设备注册通常不用过邮箱验证，机房网络一般要走一遍；新号发第一条视频，平台给的基础推流配额不同；风控对机房 IP 的初始敏感度更高，因为这类地址历史上被批量操作和爬虫用得最多。

有运营者用同一套视频模板做过对照记录：住宅 ISP 网络下新号基础播放落在 800～1000 次，机房 Hosting 网络下同样内容只有 300～500 次。这是个人测试，不是平台公布的口径，但方向和平台处理数据中心 IP 的逻辑对得上。起点差一倍，算法要不要继续往外推，就在这个基数上判断。

至于 WePC 这些 IP 干不干净，页面没有公开欺诈分。拿到机器后用 Scamalytics 或 IPQS 输进去查一遍，分数越接近 0 越好，这一步自己动手比看商家描述可靠。

## 双ISP、原生、静态，四个词别混着用

| 术语 | 实际含义 |
| --- | --- |
| 住宅 IP | 运营商分配给家庭用户的地址，数据库里登记为居民用户 |
| 双ISP IP | 服务器在机房，但 IP 段从运营商处购买，对外表现为住宅属性 |
| 原生 IP | IP 注册地和服务器所在国一致，做美区就是美国归属 |
| 静态 IP | 地址固定不变，一个账号长期绑同一条，不触发多地登录风控 |

做 TikTok 想要的组合是：住宅属性 + 目标市场原生 + 静态独享。WePC 大部分节点在标题里就标了"原生家宽"或"双ISP家宽"，英国那档 AUD$10.90 是例外，页面写明非家宽，价格便宜的原因也在这里。

## 512MB 内存能干什么，不能干什么

整张表里绝大多数套餐是 1核/512MB 或 2核/512MB，只有日本直播版给到 786MB。

这点内存跑一个网络出口、做协议转发、维持一条稳定连接完全够，但你如果打算在 VPS 里装安卓模拟器跑账号环境，512MB 是装不动的。这类机器的作用是提供出口 IP，设备指纹那层要用本地模拟器或者云手机单独解决，两边不能混为一谈。

配置真正拉开差距的地方在带宽和流量。2TB 双向流量对发短视频、日常养号很宽裕，做长时间直播或者批量上传素材就要按双向口径算余量。菲律宾和马来西亚超额后限速 5Mbps，直播中途被限速基本等于断播。
